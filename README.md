# 🖼️ Image Processing Course Repository

Welcome to the **Image Processing (IP)** course repository!  
This repository contains all course materials, experiments, assignments, and projects related to digital image processing — including image enhancement, filtering, transformation, segmentation, and feature extraction.

---

## 📚 Course Overview

The **Image Processing** course provides both theoretical and practical understanding of how digital images can be processed, analyzed, and enhanced using computational techniques.

### 🎯 Learning Objectives
- Understand fundamental concepts of image representation and sampling.
- Apply spatial and frequency domain enhancement techniques.
- Implement image restoration and filtering operations.
- Explore image segmentation, morphology, and edge detection.
- Gain experience using OpenCV, NumPy, and Matplotlib in Python.
